# Solar-and-Battery-Energy-Technology-Optimization-in-Various-Nations


For 5 nations (Kenya, Bangladesh, Bolivia, Vietnam, Ethiopia), the optimal ratio of solar to battery technology is estimated using population, budget, demand projections, as well as other variables. This is a Linear Programming Mathematical Model which uses various constraints to obtain the optimal ratio

You will need to upload the code to MATLAB to get the intended result. Given that there are 2 files of code in the repository, you should also have two files of code in MATLAB, with the energy_optimization_main being your main file.

For data csv uploads, only upload the csv files in this repository.

When you run the program on MATLAB, a few more files will be created (the program uses them to get the end results)
